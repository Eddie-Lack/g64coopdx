# g64coopdx

An online co-op version of Glover (N64) on PC, with mods, built on the [weemitt](weemitt/README.md) PC port.

**It's a prototype.** Two to sixteen players can play together online. The [roadmap](docs/discovery/roadmap.md)
says what's done and what's left.

- [Playing online](docs/playing-online.md): how to host and join a game.
- [The design](docs/discovery/README.md): what will be built, and why.
- [Hosting](docs/hosting.md): where the project's online services and downloads run.
- [The lobby server](server/README.md): the relay and the list of open games.

You'll need your own Glover (USA) ROM to play. The project never contains or shares it.
