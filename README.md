# g64coopdx

An online co-op version of Glover (N64) on PC, with mods, built on the weemitt PC port.

**Nothing is playable yet.** The project has its design and a placeholder for its lobby server. The game work
starts with phase 0 of the [roadmap](docs/discovery/roadmap.md).

- [The design](docs/discovery/README.md): what will be built, and why.
- [Hosting](docs/hosting.md): where the project's online services and downloads run.
- [The lobby server](server/README.md): the placeholder that exists today.

You will need your own Glover (USA) ROM to play. The project never contains or shares it.
